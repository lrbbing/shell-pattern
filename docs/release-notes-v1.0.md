# Shell Pattern Lab v1.0

## What this project became

Shell Pattern Lab grew from a beginner p5.js shell drawing exercise into a small generative pattern system connecting creative coding, binary data, and computational textile thinking.

## Main capabilities

- Seeded shell geometry with radial ribs, growth lines, and Ribbed, Growth, Spotted, Banding, and Field modes.
- Sine and noise scalar fields combined with adjustable weights, sampled and thresholded into a binary grid.
- Shell, rectangular Grid, and Textile views of the same field data. Textile View maps 0/1 states to structure labels and displays course/needle orientation.
- Interactive controls, seed regeneration, PNG saving, and CSV export of the binary grid.

## Learning milestones

The project records learning in VS Code and p5.js, Git and GitHub, DOM interaction, shell parameter space, scalar fields and field composition, discretization, separation of data from rendering, CSV serialization, and textile mapping.

## Scope of v1.0

This release intentionally stops before reaction-diffusion / Meinhardt systems, knitting-machine-specific formats, AYAB / knitout, needle-bed logic, jacquard backing, and production-ready textile output. Those belong to future projects, not unfinished tasks in this release.
